# uLister

## О программе

Плагин к Total Commander для внутреннего просмотра более 500 различных форматов файлов.  


## Поддерживаемые форматы

Множество популярных форматов текстовых документов, электронных таблиц, презентаций (из таких пакетов, как Microsoft Office, OpenOffice и др.), растровых и векторных изображений. Полный список приведён в файле `OutsideIn_8.5.7_Supported_File_Formats.pdf`.  


## Зависимости

При работе плагин использует сторонние библиотеки Oracle® Outside In Technology: Viewer Technology.  


## Установка

### Плагин

Последняя версия плагина доступна для скачивания на странице [github.com/evgen0xb/uLister/releases](https://github.com/evgen0xb/uLister/releases).  

1. Скачайте файл `wlx-ulister.cab`.  
2. Запустите установку двойным щелчком по скачанному файлу.  
3. Следуйте указаниям на экране.  

### Библиотеки

Библиотеки Oracle Outside In Technology: Viewer Technology доступны для скачивания на странице [www.oracle.com/middleware/technologies/outside-in-technology-downloads.html](https://www.oracle.com/middleware/technologies/outside-in-technology-downloads.html).  

Для работы на Windows 11, 10, 8, 7 рекомендуются версии:  

- `oit-8.5.8.204-vw-win-x64.zip` для 64-разрядного окружения;
- `oit-8.5.7.243-vw-win-x32.zip` для 32-разрядного окружения.

Для работы на Windows XP x64 SP2 или Windows XP x86 SP3 рекомендуются версии:  

- `oit-8.5.5.12-vw-win-x86-64.zip` для 64-разрядного окружения;
- `oit-8.5.5.12-vw-win-x86-32.zip` для 32-разрядного окружения.

1. Распакуйте скачанные архивы.
2. Из распакованной папки `redist` скопируйте:
   - 64-разрядные файлы в папку `redist64` (расположена в папке плагина);
   - 32-разрядные файлы в папку `redist32` (там же).
3. Если вы собираетесь использовать плагин на разных ОС Windows, в том числе ранних Vista или XP, создайте папки `XPdist64` и/или `XPdist32` и скопируйте в них соответствующие файлы. Подробнее см. ниже, в разделе _Многоцелевая комплектация_.

Для работы библиотек Oracle могут понадобиться актуальные версии библиотек Visual C++ Redistributables, которые доступны для скачивания со страницы [github.com/abbodi1406/vcredist](https://github.com/abbodi1406/vcredist), например. Вместо стандартной установки в систему можно ограничиться копированием в папки `redist64` и/или `redist32` файлов `msvcpN.dll` и `msvcrN.dll`, где `N` = номер версии (например, `msvcr120.dll` и т.п.).  

#### Многоцелевая комплектация

Начиная с версии 4.0.0.6 в uLister реализована возможность комплектации плагина разными версиями библиотек для работы на разных версиях ОС Windows, что может пригодиться, когда Total Commander работает в переносном (portable) режиме. Ради таких случаев механизм загрузки библиотек работает по следующему сценарию:  

- при инициализации плагин определяет версию ОС Windows;
- если версия ОС ниже 7 (т.е. Vista или XP), то поиск библиотек начинается с каталогов `XPdist64` и `XPdist32`, а если таких нет, то в каталогах `redist64` и `redist32`;
- если версия ОС выше или равна 7, то поиск библиотек начинается сразу с каталогов `redist64` и `redist32`.

Т.о. вы можете создать 4 папки — `XPdist32`, `XPdist64`, `redist32`, `redist64` — и укомплектовать плагин 4-мя версиями библиотек. Тогда при старте, например, на Windows XP, плагин будет загружать более старые библиотеки, а при старте на Windows 11 — более новые.  

### Исправление

Для работоспособности настройки `optionsdir` (_описание см. ниже_) скачайте архив `OIT_DATA_PATH support.7z` со страницы [github.com/evgen0xb/uLister/tree/main/OIT_DATA_PATH support](https://github.com/evgen0xb/uLister/tree/main/OIT_DATA_PATH%20support). Затем:  

1. Распакуйте скачанный архив.
2. Скопируйте файл `sccut.dll` с заменой существующего в папку `redist64` и/или `redist32` (в зависимости от разрядности).  


## Настройка

Из-за того, что плагин в своей работе использует сторонние библиотеки, настройки по факту разделены на две независимые части: **плагина** и **библиотек**. Библиотеки Oracle изначально снабжены своей встроенной системой настроек. Плагин же предлагает свою отдельную систему настроек. В случаях когда настройки плагина и библиотек пересекаются, приоритет плагина выше. Некоторые настройки доступны для изменения только через систему плагина.

> [!IMPORTANT]
> **О значении `skip`**  
> В настройках плагина часто встречается значение `skip`. Забегая вперёд, поясним: если настройке присвоено `skip`, плагин не занимается её обработкой, а передаёт управление встроенной системе библиотек. При любых других значениях плагин берёт управление настройкой на себя.  

### Настройки библиотек

Эти настройки доступны в окне показа документов (Viewer), во всплывающем контекстном меню по нажатию правой кнопки мыши (ПКМ). Состав команд контекстного меню зависит от формата отображаемого документа. Изменения настроек, выполненные в меню ПКМ, записываются в специальный каталог `.oit`, т.е. могут сохраняться между сеансами показа документов и применяться при каждом новом вызове Viewer. Однако, действия этих настроек можно переопределить в настройках плагина, описание которых см. ниже.

Расположение специального каталога `.oit` регулируется настройкой плагина `optionsdir`, описание которой см. ниже. Настроечные файлы в папке `.oit` — бинарные, и не предназначены для ручного редактирования.

### Настройки плагина

Эти настройки хранятся в файле `ulister.ini`, который может располагаться в одном из каталогов, согласно следующему приоритету:  

1. Каталог плагина.
2. Каталог, определённый в переменной `%COMMANDER_INI%`.
3. Каталог, определённый в переменной `%APPDATA%`.

При инициализации плагин ищет файл `ulister.ini` в своём каталоге. Если не находит, ищет в `%COMMANDER_INI%` и т.д.  

Если длина пути к файлу `ulister.ini` превысит 260 символов, то плагин не сможет прочитать из него свои настройки (из-за ограничений Windows).  

Файл `ulister.ini` редактируется вручную. Настройки в нём распределены по трём секциям:  

1. `[ulister]`
2. `[clipboard]`
3. `[viewer]`

#### Секция `[viewer]`

В секции `viewer` расположены настройки отображения форматированных текстовых документов, HTML, EMAIL, растровой и векторной графики. Эти настройки пересекаются с аналогичными встроенными настройками библиотек, доступными из меню ПКМ → View и Size, однако приоритет у настроек плагина выше.

> [!IMPORTANT]
> **Общее пояснение**  
> При просмотре документа настройки плагина и библиотек взаимодействуют следующим образом.  
>  
> Если выбрано значение `skip`. Открываем документ, вызываем меню ПКМ и в группах View и Size выбираем режим отображения. Этот режим применяется к текущему документу, а также ко всем последующим документам. Так работает система настроек библиотек.
>  
> Если выбрано любое другое значение, кроме `skip`. При открытии документа к нему применяется режим отображения, указанный в настройках плагина. При этом в окне просмотра работает переключение режимов из меню ПКМ → View/Size. Выбранный в меню ПКМ режим действует до закрытия текущего документа или до переключения на просмотр следующего документа. При открытии следующего документа настройки из меню ПКМ сбрасываются, а отображение изменяется согласно настройке плагина.  

> [!WARNING]
> **Внимание**  
> Из-за ошибки в библиотеках Oracle, настройки из этой секции считываются плагином только при инициализации. Поэтому, если вы отредактировали одну из них, перезапустите Total Commander для применения изменений.

## Компиляция

Для редактирования исходных кодов проекта в современных версиях Visual Studio используйте файл `vs2015.sln`.  
Для компиляции проекта в компактный код с поддержкой Windows XP 32/64 с помощью Visual Studio 2005 (для x64 понадобится версия Pro) используйте файл `vs2005.sln`.  
Для создания файла `wlx-ulister.cab` — автоматического установщика плагина в Total Commander, используйте скрипт `MAKECAB.CMD`.
