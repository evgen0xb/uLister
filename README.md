# uLister

Версия: **4.2.0.0**  

## О программе

Плагин к Total Commander для внутреннего просмотра более 500 различных форматов файлов.  


## Поддерживаемые форматы

Плагин обеспечивает просмотр множества форматов, используемых в таких популярных программах, как Microsoft Office (Word, Excel, PowerPoint), OpenOffice и LibreOffice (Writer, Calc, Impress, Draw), Corel WordPerfect Office, IBM Lotus, Microsoft Outlook, Apple Mail, AutoCad, Microsoft Visio. В том числе:  

- форматированные текстовые документы и их шаблоны: _.doc_, _.docx_, _.rtf_, _.dot_, _.dotx_, _.odt_, _.ott_, _.wpd_ и др.;
- электронные таблицы и их шаблоны: _.xls_, _.xlsx_, _.xlsb_, _.xlt_, _.xltx_, _.ods_, _.ots_, _.qpw_ и др.;
- электронные презентации и их шаблоны: _.ppt_, _.pptx_, _.odp_, _.otp_, _.shw_ и др.;
- электронные письма: _.msg_, _.eml_;
- персональные и автономные хранилища данных Microsoft Outlook: _.pst_, _.ost_;
- базы данных: _.mdb_ и др.;
- проектные документы: _.dwg_, _.dxf_;
- визуальные схемы: _.vmd_ (Microsoft Visio 2003–2010);
- интернет-страницы: _.htm_, _.html_;
- архивы:  
  - _.7z_ (кроме split);
  - _.cab_ (Microsoft Cabinet с компрессией MSZIP);
  - _.rar_ (кроме solid);
  - _.zip_ (и его подмножества _.apk_, _.jar_, _.xpi_ и т.п.);
  - _.tar_, _.gz_ и др.
- растровые и векторные изображения.

Полный список приведён в файле `OutsideIn_8.5.7_Supported_File_Formats.pdf`, а также [на сайте Oracle](https://docs.oracle.com/en/middleware/standalone/outsidein/8.5/oit-supported-fileformats/toc.htm).  


## Зависимости

При работе плагин использует сторонние библиотеки Oracle® Outside In Technology: Viewer Technology (далее **OIT**).  

Библиотеки OIT используют файлы библиотек Microsoft Visual C++ Redistributable.  

Полное техническое описание библиотек OIT содержится в Oracle® Outside In Viewer Developer's Guide (далее **OIVWR**) и доступно [на сайте Oracle](https://docs.oracle.com/en/middleware/standalone/outsidein/8.5/oivwr/index.html) (для версии 8.5.8), а также в репозитории плагина, файл [OIVWR 854.pdf](https://github.com/evgen0xb/uLister/blob/main/doc/OIVWR%20854.pdf).


## Установка

### Плагин

Последняя версия плагина доступна для скачивания на странице [github.com/evgen0xb/uLister/releases](https://github.com/evgen0xb/uLister/releases).  

1. Скачайте файл `wlx-ulister.cab`.  
2. Находясь в окне Total Commander, запустите установку двойным щелчком по скачанному файлу.  
3. Следуйте указаниям на экране.  

### Библиотеки

Библиотеки OIT доступны для скачивания на странице:  
[www.oracle.com/middleware/technologies/outside-in-technology-downloads.html](https://www.oracle.com/middleware/technologies/outside-in-technology-downloads.html).  

Для работы на Windows 11, 10, 8, 7 рекомендуются версии:  

- `oit-8.5.8.204-vw-win-x64.zip` для 64-разрядного окружения;
- `oit-8.5.7.243-vw-win-x32.zip` для 32-разрядного окружения.

Для работы на Windows XP x64 SP2 или Windows XP x86 SP3 рекомендуются версии:  

- `oit-8.5.5.12-vw-win-x86-64.zip` для 64-разрядного окружения;
- `oit-8.5.5.12-vw-win-x86-32.zip` для 32-разрядного окружения.

1. Распакуйте скачанные архивы.
2. Из распакованной папки `redist` скопируйте:
   - 64-разрядные файлы в папку `redist64` (расположена в папке плагина);
   - 32-разрядные файлы в папку `redist32` (там же).
3. Если вы собираетесь использовать плагин на разных ОС Windows, в том числе ранних Vista или XP, создайте папки `XPdist64` и/или `XPdist32` и скопируйте в них соответствующие файлы. Подробнее см. в разделе _Многоцелевая комплектация_.

Актуальные версии библиотек Microsoft Visual C++ Redistributables доступны для скачивания на официальной странице [Microsoft](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) или из альтернативных источников, например, [github.com/abbodi1406/vcredist](https://github.com/abbodi1406/vcredist). Вместо стандартной установки в систему можно ограничиться копированием в папки `redist64` и/или `redist32` файлов `msvcpN.dll`, `msvcrN.dll` и `vcruntimeN.dll` (если есть), где `N` = номер версии (например, `msvcr140.dll` и т.п.):  

- для OIT 8.5.7 и 8.5.8 необходим VC++ 14.0 (`msvcp140.dll`, `msvcr140.dll` и `vcruntime140.dll`);
- для OIT 8.5.5 — VC++ 12.0 (`msvcp120.dll` и `msvcr120.dll`).



#### Многоцелевая комплектация

Начиная с версии 4.0.0.6 в uLister реализована возможность комплектации плагина разными версиями библиотек OIT для работы на разных версиях ОС Windows, что может пригодиться, когда Total Commander работает в переносном (portable) режиме. Ради таких случаев механизм загрузки библиотек работает по следующему сценарию:  

- при инициализации плагин определяет версию ОС Windows;
- если версия ОС ниже 7 (т.е. Vista или XP), то плагин ищет библиотеки в папках `XPdist64` и `XPdist32`, а если таких нет, то в папках `redist64` и `redist32`;
- если версия ОС выше или равна 7, то поиск библиотек начинается сразу с папок `redist64` и `redist32`.

Т.о. вы можете создать 4 папки — `XPdist32`, `XPdist64`, `redist32`, `redist64` — и укомплектовать плагин 4-мя версиями библиотек OIT. Тогда при старте, например, на Windows XP, плагин будет загружать более старые библиотеки, а при старте на Windows 11 — более новые.  

### Исправление

> [!IMPORTANT]
> Для работоспособности настройки `optionsdir` (_описание см. в разделе Секция ulister_) скачайте архив `OIT_DATA_PATH support.7z` со страницы [github.com/evgen0xb/uLister/tree/main/OIT_DATA_PATH support](https://github.com/evgen0xb/uLister/tree/main/OIT_DATA_PATH%20support). Затем:  
>  
> 1. Распакуйте скачанный архив.
> 2. Скопируйте файл `sccut.dll` с заменой существующего в папку `redist64` и/или `redist32` (в зависимости от разрядности).


## Настройки

Из-за того, что при работе плагином используются функции сторонних библиотек, доступ к настройкам этих функций по факту осуществляется двумя разными способами: через **ini-файл плагина** и через **интерфейс библиотек (меню ПКМ)**. Происходит это по следующей причине.

Библиотеки OIT изначально снабжены своим интерфейсом управления настройками. Однако, не все настройки через него доступны. Чтобы восполнить этот пробел, в плагине организован свой, отдельный доступ к управлению настройками — через ini-файл.  

> [!IMPORTANT]
> **О значении `skip`**  
> Если настройке в ini-файле плагина присвоено значение `skip`, то управление такой настройкой осуществляется через интерфейс библиотек. При остальных значениях — через ini-файл плагина.  
>  
> **О взаимодействии двух способов настроек**  
> Настройки некоторых функций доступны как из интерфейса библиотек, так и через ini-файл плагина. Если во время показа документа из интерфейса библиотек меняется та настройка, которая определена в ini-файле (любое значение, кроме `skip`), то это изменение действует до закрытия текущего документа. При открытии следующего документа изменённая настройка вернётся к значению, указанному в ini-файле. Примеры см. в описаниях секций ini-файла.

### Меню ПКМ

В библиотеках интерфейс доступа к настройкам организован в виде всплывающего контекстного меню по нажатию правой кнопки мыши (ПКМ) при показе документов в окне Lister. Состав команд этого меню зависит от формата отображаемого документа.  

Изменения настроек, выполненные в меню ПКМ, записываются в специальную папку `.oit`, т.е. могут сохраняться между сеансами показа документов и применяться при каждом новом вызове Lister.  

Расположение специальной папки `.oit` регулируется настройкой ini-файла `optionsdir` <i>(описание см. в разделе Секция ulister)</i>. Файлы в папке `.oit` — бинарные, и не предназначены для ручного редактирования.  

### INI-файл плагина

Именуется `ulister.ini` и может располагаться в одной из папок, согласно следующему приоритету:  

1. Папка плагина.
2. Папка, определённая в переменной `%COMMANDER_INI%`.
3. Папка, определённая в переменной `%APPDATA%`.

Длина пути к `ulister.ini` не должна превышать 260 символов (ограничение Windows), иначе плагин не сможет к нему обратиться.  

Если при старте плагин не обнаружит `ulister.ini`, то создаст его в своей папке, с настройками по умолчанию.  

Изменение настроек в `ulister.ini` выполняется вручную, путём редактирования. Если во время редактирования Total Commander был открыт, то для применения изменений его необходимо перезапустить, поскольку плагин считывает ini-файл при старте.  

Содержимое `ulister.ini` распределено по трём секциям:  

1. `[ulister]` — настройки работы плагина.
2. `[clipboard]` — настройки копирования в буфер обмена при просмотре документов.
3. `[viewer]` — настройки отображения документов.

#### Секция `[clipboard]`

Настройки копирования в буфер обмена при просмотре документов.  


> [!IMPORTANT]
> **О взаимодействии с меню ПКМ**  
> Значения части настроек этой секции можно также изменить через меню ПКМ → Options → Clipboard... → диалог Clipboard options. При этом взаимодействие со значениями в ini-файле будет следующим.  
>  
> Если в ini-файле выбрано любое значение, кроме `skip`, то при его изменении через меню ПКМ, новое значение будет действовать только до закрытия текущего документа. При открытии следующего документа будет применено значение из ini-файла.
> 
> Если в ini-файле выбрано значение `skip`, то изменение значения из меню ПКМ будет сохранено после показа текущего документа и применено к последующим документам.

В документах некоторых форматов выделенный блок можно скопировать в буфер обмена, либо перетащить мышкой.  

При просмотре содержимого таких файлов, как _.zip_, _.cab_, _.pst_ и т.п. (простые контейнеры), двойной щелчок по имени файла приводит к его распаковке во временную папку с последующим открытием в новом окне Lister для просмотра.  

При просмотре электронных писем одинарный щелчок по ссылке на прикреплённый файл распаковывает его во временную папку и открывает в новом окне Lister для просмотра. При этом имя файла меняется на произвольное, а расширение на _.tmp_. То же происходит со встроенными изображениями по двойному щелчку.  

<sup>ℹ️</sup> _Для не-графических документов изменение масштаба реализуется только посредством изменения размера шрифта. В некоторых случаях это приводит к незначительному сбою форматирования документа, что всё же лучше, чем совсем ничего. В библиотеках OIT так и не было реализовано полноценное масштабирование для не-графических документов, и, похоже, интерфейс сообщений от мыши для масштабирования и горизонтальной прокрутки был, напротив, специально программно затруднён во избежание артефактов визуализации._
